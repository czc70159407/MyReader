## 1. 功能概述

### 1.1 功能目标与用户价值

**目标**：让用户在 EPUB 阅读中，以最小操作成本把正文调整到「一眼舒服」的字号，且该偏好跨会话、跨文档、跨重启稳定生效。

**用户价值**：

1. **阅读舒适度**：不同用户、不同时段（通勤 / 睡前 / 桌面）对字号需求差异大，字号是阅读舒适度的第一杠杆。
2. **零学习成本**：调节入口与操作符合主流阅读器（微信读书）心智，点开即懂。
3. **稳定可预期**：字号作为「偏好」而非「会话临时值」——换文档、杀进程、重启后仍保持，不反复调。
4. **不丢位置**：调字号触发整书重排导致页数变化时，阅读位置以「内容等义」保持（remap），用户不因调字号而迷路。

### 1.2 参照产品（微信读书）与差异化

| 维度 | 微信读书 | MyReader（本 PRD 定稿） |
|---|---|---|
| 调节入口 | 阅读中点屏幕 → 底部工具条 →「Aa」 | 阅读器顶栏第 4 动作「Aa」（`FormatSize`，CD「显示设置」）+ 设置页「显示」分区，双入口同源 |
| 调节方式 | 连续滑杆（A− → A+） | **离散 5 档**（决策依据见 §3.2） |
| 生效 | 拖动即实时预览 | 点选档位即整书重排、即时生效 |
| 记忆 | 全局记忆 | 全局偏好（DataStore），跨会话/文档/重启 |
| 联动 | 字号 + 字体 + 行距/段距 + 页边距 + 背景色 + 翻页方式 | 字号（已实现）；字体/行距/段距/页边距为 `[规划 P2]`（§3.5）；深色主题属 UI 主题维度，与字号正交 |

**核心差异定位**：MyReader 只做「字号」这一件事并做到位（5 档离散 + 即时重排 + 内容等义 remap），不做微信读书的全量排版面板，避免引入 MuPDF reflow 未暴露的排版参数（字距/段距）导致的高成本低收益。

## 2. 适用场景与用户画像

| 画像 | 场景 | 字号诉求 |
|---|---|---|
| **B · 多格式电子书读者**（`interaction.md` §1.2） | 睡前低光、通勤晃动、桌面大屏读 EPUB | 睡前调大、白天调小，跨书保持 |
| 弱视 / 老年用户 | 需要显著放大正文字号 | 「大」档（EM 16）可读 |
| 小屏 / 折叠屏用户 | 窄视口下默认字号偏密 | 调小以增加单屏信息量 |

**成功判定**（对齐 `interaction.md` §1.3 S5「偏好固化」）：调字号立即生效、位置不丢；重启后保持；不同 EPUB 文档间一致。

## 3. 功能需求

### 3.1 调节入口

两个入口，**写同一份全局偏好**，任意入口改动即时双向同步：

| 入口 | 路径 | 形态 | 分派 |
|---|---|---|---|
| 阅读器顶栏 | 打开 EPUB → 顶栏第 4 动作「Aa」 | `ModalBottomSheet`（`DisplaySheet`） | 按 `doc.reflowable` 分派：EPUB 显字号 5 档；PDF/CBZ/XPS 显缩放 5 档 |
| 设置页 | 书架 → 设置 →「显示」分区 | 内嵌单选行（`RadioRow`） | 同一偏好的第二入口 |

- 顶栏动作顺序（M15 后）：`标注 / 目录 / 跳页 / 显示 / 模式`（5 个，见 `components/top-bar.md`）。
- 分派规则：`reflowable == true → 字号`；否则 → 缩放。二者是**两个独立偏好**，UI 共用入口但互不串值。

### 3.2 调节方式：档位 vs 连续（决策 D12）

**定稿：离散 5 档**（`ReaderFontScale`），而非微信读书式连续滑杆。

| 档位 | `em`（pt） | 标签 | 相对上一档 |
|---|---|---|---|
| `SMALL` | 6 | 小 | — |
| `MEDIUM_SMALL` | 8 | 较小 | +33% |
| `DEFAULT` | 10 | 标准 | +25% |
| `MEDIUM_LARGE` | 13 | 较大 | +30% |
| `LARGE` | 16 | 大 | +23% |

**理由**：

1. **性能**：EPUB 字号变化 = 整书 relayout（重排是 `O(全书)` 操作，走 `Dispatchers.Default`）。连续滑杆拖动会产生几十上百次重排，ANR 风险高。
2. **可辨性**：相邻档视觉差 ≥ 23%，一眼可辨（真机教训：早期 8/9/10 相邻仅差 12.5%，用户切「小↔较小」无感，误判功能失效）。
3. **零回归**：`标准 = EM 10` 与 MuPDF 默认排版字号对齐，默认档与历史行为完全等价。

**若未来引入连续调节**（不做，仅记录边界）：必须以「拖动结束（松手）才触发重排」+ 拖动中仅做字号数字预览，且需重新评估 ANR 与 `MuPDFCore.layout` 的连续调用成本。

### 3.3 预览与即时生效

- **点选即重排**：点某个档位 Chip → 该文档立即按新 `em` 整书重排，无二次确认。
- **水平分页**：`appliedFontEm` 差分 → `scheduleRelayout()`（与尺寸变化同一去抖路径，后台线程）。
- **垂直滚动**：`core.layout(currentPage, …)` remap 后锚定到首可见页对应内容；页尺寸缓存失效（`evictAll(invalidatePageSizes=true)`）。
- **位置保持（内容等义）**：重排后页数变化时，通过 `layout(currentPage)` remap + `onPageCountChanged` 上抛，把「页 N」映射为「重排后的同内容位置」；顶栏分母实时更新。
- **即时性反馈**：面板不关闭即见正文变化；面板本身是 `ModalBottomSheet`，底部内容在面板上方，字号变化直接可见（无需关闭面板预览）。

### 3.4 默认值与记忆

| 项 | 取值 |
|---|---|
| 默认档 | `DEFAULT`（标准，EM 10） |
| 回落档 | 读失败 / 未知 name → `FALLBACK = DEFAULT` |
| 记忆范围 | **全局偏好**（非会话态）：所有 EPUB 文档共享同一字号，跨会话 / 跨文档 / 跨重启 |
| 持久化 | DataStore `settings_prefs`，name 字符串存储 + legacy int key 兼容（纪律同 `ThemeMode`，枚举项可重排/插入，不依赖 ordinal） |
| 写失败 | 静默降级（不打断阅读） |

> 语义边界：字号是「全局偏好」（同主题），区别于「阅读模式 H/V」的「会话态」（`screens/reader.md` §4.4）——字号跨文档一致，阅读模式每文档独立记忆。

### 3.5 与其他排版设置联动（字号 / 字体 / 行距 / 段距 / 页边距）

> 微信读书「Aa」面板将字号、字体、行距、段距、页边距、背景色、翻页方式同屏联动。MyReader 按「MuPDF reflow 暴露能力」分档落地，现状与规划如下：

| 排版设置 | 微信读书参照 | MyReader 现状 | 规划 / 说明 |
|---|---|---|---|
| **字号** | 连续滑杆 | `[已实现 M15]` 5 档 | 本文档主体 |
| **字体** | 系统默认 / 思源宋体等 | `[未做]` | `[规划 P2]`：需嵌入字体文件 + 影响 AGPL 体积；MuPDF reflow 支持 font 指定，成本可控，价值中等 |
| **行距 / 段距** | 滑杆调节 | `[未做]` | `[规划 P2]`：**MuPDF reflow 不暴露行距/段距参数**（`m15-plan.md` §1 非目标），需 fork 补 API，成本高 |
| **页边距** | 滑杆调节 | `[未做]` | `[规划 P2]`：=「边距裁切」独立里程碑，需 S0 预研（MuPDF 内容边界 bbox API 未暴露，见 `m15-plan.md` §8） |
| **背景色 / 护眼** | 白/米/绿/黑 | `[已实现]` 深色主题 | 属 UI 主题（`ThemeMode` 三选一），与字号正交，不在本 PRD 范围 |
| **翻页方式** | 仿真/平移/滚动 | `[已实现]` 水平分页 / 垂直滚动 | 属「阅读模式」，与字号正交 |

**联动设计原则**：字号与上述设置**相互独立、正交叠加**——调字号不改变字体/行距/页边距/阅读模式，各设置单独记忆、单独生效，避免「调一个字号把其它全重置」的耦合。

## 4. 边界与异常

### 4.1 字号范围限制

| 项 | 规则 |
|---|---|
| 最小 | EM 6（「小」），下限防「过小不可读 + 重排页数爆炸（页数反比于字号）→ 内存/性能失控」 |
| 最大 | EM 16（「大」），上限防「单字过大溢出窄视口 + 长词无处换行」 |
| 越界输入 | 不存在自由输入，档位为封闭枚举，天然无越界 |
| 非法持久化值 | 读失败 / 未知 name → 回落 `DEFAULT`，不崩溃 |

### 4.2 超长文本换行

- 正常长文本：MuPDF reflow 自动断行换行，字号调大 → 单行字符数减少 → 页数增加，属预期。
- **极长无断点单词 / URL / 连续符号**（超过一行宽度）：可能溢出视口或整行不换行。
  - 现状：依赖 MuPDF reflow 的默认断行策略（非本功能可控）。
  - 验收口径：不崩溃、内容可滚动查看即为通过；单行溢出若出现，记为 `[缺口]` 并评估是否需 fork 补 break-anywhere。

### 4.3 图文混排

- 字号仅影响**文字排版**（`em`），**图片不随字号缩放**（图片按容器宽度 / 原尺寸展示）。
- 图文混排页：字号调大 → 文字重排、图片位置随之流动，图文相对位置由重排引擎决定，不保证「图 + 对应文字同屏」。
- 验收口径：图片不拉伸变形、不遮挡文字、可滚动查看；「图文同屏」不做承诺。

### 4.4 水平分页 / 垂直滚动差异

| 模式 | 字号生效路径 | 页数 | 位置保持 |
|---|---|---|---|
| 水平分页 | `appliedFontEm` 差分 → `scheduleRelayout` | 随字号变化（分母实时更新） | `layout(currentPage)` remap 保持内容等义 |
| 垂直滚动 | `LaunchedEffect(doc, fontScale)` → `layout(currentPage, …)` remap 后锚定 | 随字号变化 | 锚定首可见页对应内容 |

- **统一承诺**：两模式下调字号，位置均「内容等义」保持；顶栏分母随重排更新。
- 已知限制（`m15-plan.md` §6）：垂直 EPUB relayout 后页内像素偏移不保留（对齐页顶），同宽度下精确、跨宽度近似。

### 4.5 其他边界

| 边界 | 行为 |
|---|---|
| 重排失败 | 不静默：写日志（`MuPdfRelayout` 警告），页面回落当前页，不崩溃 |
| ANR 防护 | 重排全程 `Dispatchers.Default`，水平去抖、垂直 remap，不在主线程整书重排 |
| 打开即重排 | 打开 EPUB 时以「当前字号」重排（而非先默认再跳档），避免首帧闪变 |
| 跨文档一致性 | 全局偏好，任何 EPUB 打开即用当前字号 |
| 会话态隔离 | 字号变更**不重置**会话态（模式、选区、书签面板），仅触发重排 |

## 5. 兼容性要求

| 维度 | 要求 |
|---|---|
| 格式 | 仅 reflowable（EPUB）消费字号；PDF/CBZ/XPS 走缩放分派，不受字号影响；TXT 不受字号影响（P2） |
| 持久化迁移 | name 字符串存储，legacy int key 兼容读取，写时 `remove` 旧 key（同 `ThemeMode` 纪律） |
| 旧包升级 | 无字号偏好 → 回落 `DEFAULT`（标准），零迁移错误 |
| 备份 | 字号为设备级偏好，随 DataStore 存储，不随备份 zip（备份只含文档/目录/书签/标注）——恢复后字号保持设备当前值 |
| 系统字号（SP 缩放） | 阅读字号（`em` pt）与系统字号（SP）独立，互不影响；系统字号 200% 下 UI 不裁切（`accessibility.md` §4） |
| RTL | 重排由 MuPDF 引擎处理，字号切换不改变文本方向语义 |
| Android 版本 | 沿用项目 minSdk 26，无新增 API 依赖 |

## 6. 验收标准

> 完整验收方案与真机证据见 `docs/m15-plan.md` §5；此处为可复现的「happy + 边界 + 失败」三级清单。

**前置**：库内已有 1 个多章节 EPUB（含图文混排）。

| # | 场景 | 操作 | 预期 |
|---|---|---|---|
| 1 | 入口分派 | EPUB 打开「Aa」 | 面板显「字号」5 档；PDF 打开「Aa」显「缩放」5 档 |
| 2 | 调大 | EPUB「Aa」→「大」 | 页数增加（整书重排）、当前位置内容等义、顶栏分母随动 |
| 3 | 跨会话 | 调「大」→ 杀进程 → 重进 | 仍「大」，Chip 选中态高亮 |
| 4 | 跨文档 | 调「大」→ 打开另一 EPUB | 仍是「大」 |
| 5 | 旋转 | 「大」下旋转横/竖 | 重排到新视口、位置保持、分母随动 |
| 6 | 双入口同源 | 阅读器改档 → 设置页看；设置页改档 → 阅读器生效 | 双向选中态一致、即时生效 |
| 7 | 最小/最大 | 切「小」与「大」 | 均可读、不溢出、无崩溃、页数在合理区间 |
| 8 | 图文混排 | 「大」下滚至含图页 | 图片不拉伸变形、不遮挡文字、可滚动 |
| 9 | 超长文本 | 「大」下滚至长 URL/长单词段 | 不崩溃、可滚动；单行溢出记为 `[缺口]` |
| 10 | 位置保持 | 第 N 页调大 → 再调回标准 | 位置内容等义，不跳回首页 |
| 11 | 360dp 窄屏 | 顶栏 5 动作 | 不溢出（含字号入口） |
| 12 | 深浅主题 | 深色下开面板 | 面板配色随主题，对比度达标 |
