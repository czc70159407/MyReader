# 组件 · 弹窗族

- 状态：评审通过
- 优先级：P0（D1 恢复确认）/ P2（D8 对比度、T7 校验）
- 代码落点：`feature/library/{FolderPickerDialog,NewFolderDialog,OperationDialogs,ImportSummaryDialog}.kt`、`feature/reader/{GoToPageDialog,ReaderScreen}.kt`、`feature/settings/SettingsScreen.kt`

## 1. 通用规则

1. 统一使用 `AlertDialog`（Material3 默认 28dp 圆角），内边距 24dp。
2. 主按钮 `TextButton`，右对齐；破坏性动作文字 `colorScheme.error`。
3. 输入类弹窗：单行、`singleLine = true`，非法输入用 `isError`，非法/空值**禁用**主按钮（不靠点击报错）。
4. 同一时刻最多一个弹窗（浮层不叠加）；需要"在弹窗内再开弹窗"时，子弹窗关闭后回到父弹窗（现有 `FolderPickerDialog` → `NewFolderDialog` 即此模式）。
5. 弹窗 `onDismissRequest` 必须与「取消」同义（不产生副作用）。
6. 键盘：输入弹窗在真机上必须验证按钮不被 IME 遮挡；若被遮挡，改用 `Dialog` + `imePadding` 或滚动容器。

## 2. 弹窗清单

### 2.1 选择目录（`FolderPickerDialog`）

```
┌────────────────────────────┐
│ 选择目录                     │
│ ┌────────────────────────┐ │
│ │ → 根目录                 │ │ 选中背景 secondaryContainer
│ │ ▸ A                     │ │
│ │   ▸ B                   │ │ 限高 360dp，可滚动
│ │ + 新建子目录              │ │
│ │ 不能移动到自身或其子目录   │ │ 仅禁选时显示（error 色）
│ └────────────────────────┘ │
│              [取消] [确定]   │ 非法选中时「确定」禁用
└────────────────────────────┘
```

- 选中态由 `selectedId` 单一来源驱动；同一槽位切换不同目标时重置（`remember(initialSelectedId)`）。
- 长按在 picker 内禁用（目录管理只在书架页做）。
- 弹窗内新建子目录：以当前选中项为父，创建成功后自动选中新目录；移动文件夹场景下新目录若属禁选集需实时并入。

### 2.2 新建文件夹（`NewFolderDialog`）

- 输入 label「文件夹名称」；空/全空格 → 创建禁用。
- `[建议 T7]` 输入期校验：≤64 字符、过滤控制字符；重名改为行内错误（`inline_name_duplicate`）。
- `[已实现]` 重名兜底：业务层抛错 → Snackbar。

### 2.3 重命名（`RenameDialog`，文件夹/文档共用）

- 预填旧名并**全选**（输入即替换）。
- 文档：有扩展名时锁定（`suffix` 展示、不可编辑，预填剥离、提交拼接）；无扩展名不锁。
- 空/全空格 → 确定禁用；重名由业务层兜底（同父/同目录）。

### 2.4 删除确认（`DeleteConfirmDialog`）

- 正文必须包含后果：文件夹「其中文档将移至根目录」；文档「物理文件一并删除」。
- 主按钮「删除」用 `error` 色；无二次输入确认（成本与收益不匹配）。

### 2.5 跳页（`GoToPageDialog`）

- 预填当前页（1 基）。
- 输入过滤：仅数字、长度 ≤ 7；label 常驻范围「页码（1 - {pageCount}）」。
- `isError = !valid`（`target !in 1..pageCount`）；`[建议]` 增加 `supportingText` 说明合法范围。
- 页码范围随实时页数变化（epub 重排后弹窗内范围应为当前值）。

### 2.6 密码（`PasswordDialog`，`ReaderScreen` 私有）

- 标题「文档已加密」；密码框掩码、单行；空 → 「打开」禁用。
- 提交失败：顶部内联 `inline_password_wrong`（error 色），**保留已输入内容** 供修正。
- 取消 = 返回书架；返回前先让弹窗离开组合再导航（避免残影悬在转场之上）。

### 2.7 重复导入确认

- 文案带已有文档标题；「仍导入」= 对该文件 force 重导；「跳过」= 继续下一个文件。
- 导入循环在此期间挂起，不会并发弹多个。

### 2.8 导入汇总（`ImportSummaryDialog`）

- 标题：`ok_import_summary_title`（目录）/ `ok_import_summary_title_multi`（单文件多选，D5）。
- 首行「共扫描 {total} 个可导入文档」`bodyMedium` + `onSurfaceVariant`。
- 计数行 `bodySmall`，**仅 > 0 显示**（「新建/复用目录」恒显示为 `created / reused`）。
- 明细区：标题「明细：」+ 每行 `· {path} —— {reason}`，`labelSmall`，最多 50 条（其余仅计入总数），整块可滚动。
- 单按钮「知道了」。
- `[建议 P2]` 明细按原因分组或折叠，避免 50 行平铺。

### 2.9 恢复备份确认（D1 / T1，新增）

```
┌────────────────────────────┐
│ 从备份恢复                   │
│ 将合并备份中的 {n} 个文档 /   │
│ {m} 个目录：同名记录以备份为准，│
│ 备份之外的数据不受影响。       │
│ 是否继续？                    │
│              [取消] [继续恢复] │
└────────────────────────────┘
```

- 触发：SAF 选完 zip 之后、读取流之前。
- 取消：不打开流、不进入 busy 态。
- 确认：进入 busy 态，展示进度环 + 线性进度。

### 2.10 移动失败提示（现有）

- 标题「无法移动」，正文 `err_subtree_load`，单按钮「知道了」。
- 该路径下**不渲染**目录选择器（避免用户选到非法目标）。

## 3. 状态与校验矩阵

| 弹窗 | 输入非法 | 提交中 | 提交失败 | 取消语义 |
|---|---|---|---|---|
| 选择目录 | 禁选目标 → 红字 + 确定禁用 | 无（同步导航） | 无 | 不移动，留在原页 |
| 新建文件夹 | 空 → 禁用 | 无进度（本地写） | Snackbar（重名/IO） | 不创建 |
| 重命名 | 空 → 禁用 | 无 | Snackbar | 不改名 |
| 删除确认 | 无输入 | 无进度 | Snackbar | 不删除 |
| 跳页 | 越界/非数字 → `isError` + 禁用 | 无 | 无 | 不跳转 |
| 密码 | 空 → 禁用 | 无进度（打开中整屏 Loading） | 内联错误 + 重试 | 返回书架 |
| 重复导入 | 无输入 | 导入循环挂起 | 归入整体导入结果 | 跳过该文件 |
| 导入汇总 | 无输入 | — | — | 仅关闭 |
| 恢复确认 | 无输入 | 确认后转 busy | Snackbar `err_backup_op` | 不读流、不恢复 |

## 4. 无障碍

| 项 | 要求 | 现状 |
|---|---|---|
| 触达 | 按钮与可点行 ≥ 48dp | `[已实现]`（picker 行 48dp，TextButton 默认 48dp 高） |
| 初始焦点 | 含输入框的弹窗焦点落在输入框 | `[建议 T5]` |
| 关闭后焦点 | 回到触发元素（卡片/顶栏按钮） | `[建议 T5]` |
| 错误朗读 | `isError` 文本被朗读 | 依赖 Compose 默认；`[建议]` 用 `liveRegion` 确保 |
| 列表语义 | picker 树结构可理解为层级列表 | `[缺口 P2]` 建议加 `collectionInfo` |
| 按钮禁用原因 | 禁用状态可被读屏读出 | `[已实现]`（`enabled=false` 自动播报） |

## 5. 验收场景

1. 新建文件夹输入全空格：创建按钮禁用；输入 65 字符：截断或提示（T7 后）；
2. 重命名文档：预填全选，扩展名灰显不可编辑，输入新名后扩展名自动保留；
3. 删除文件夹：正文含「文档将移至根目录」，删除后 Snackbar 正确；
4. 跳页：输入 0 / 999 / 字母 → 数字被过滤、越界时确定禁用、错误态可见；
5. 密码：空不可提交；错误密码内联提示且已输入内容保留；取消返回书架无残影；
6. 重复导入：逐个弹窗，选择「跳过」后继续下一个文件的导入；
7. 导入汇总：0 计数行不显示；>50 条明细时对话可滚动且行数被截断；
8. 恢复确认（T1）：取消后进度环不出现、无 Snackbar；确认后出现进度并有完成提示；
9. 软键盘弹出：输入框与按钮同时可见（真机逐弹窗验证）。
