# 响应式与无障碍规格

> 本文件是响应式与无障碍的**唯一**验收清单。实现现状见 [`../ui-design.md`](../ui-design.md)；每条结论必须能在真机或 Compose 测试中复现。

## 1. 响应式矩阵

| 场景 | 要求 | 现状 | 验证方式 |
|---|---|---|---|
| 手机竖屏 360dp | 书架 ≥3 列；顶栏动作不溢出、不换行、不压缩标题到不可读 | `[已实现]` 网格；`[缺口]` 6 图标需实测 | 360dp 模拟器截图 |
| 手机横屏 640dp+ | 书架列数随宽度增加；阅读器渲染区铺满，无留白 | `[已实现]`（`Adaptive(108dp)`） | 旋转后截图 |
| 平板 / 折叠屏展开 | 同上；设置页内容建议限宽 600dp 居中 | `[建议 P2]` 限宽未做 | 840dp 模拟器 |
| 分屏（600dp 以下多窗口） | 尺寸变化后渲染重建，不白屏、不丢进度 | `[已实现]`（去抖 150ms + 锁存页） | 分屏拖动后截图 + 页码比对 |
| epub 旋转/分屏 | 按内容锚点重排，顶栏分母实时更新 | `[已实现]`（`onPageCountChanged`） | 竖→横→竖 三次分母 |
| 软键盘弹出 | 对话框内输入时，主/次按钮与输入框均可见 | `[已知坑]` 真机曾出现按钮被顶移 | 弹窗截图 + 重新定位点击 |
| 字体缩放 200% | 顶栏双行标题、卡片 2 行标题、汇总对话框不裁切关键信息 | 未系统验证 | 系统字号最大后逐页走查 |
| RTL | 缩进用 `start/end`，箭头用 `AutoMirrored` | `[已实现]` | 开发者选项强制 RTL |
| 深色模式 | 三选一实时生效；首帧不闪白 | `[已实现]` | 设置切换 + 冷启动 |
| 大屏阅读器 | 垂直模式长文档滚动流畅，无 OOM | `[已实现]`（字节预算 LruCache） | 200+ 页 PDF 连续滚动 |

## 2. 无障碍清单（逐项打勾）

### 2.1 触达与操作

| 项 | 要求 | 现状 |
|---|---|---|
| 最小触达 | 所有可点元素 ≥ 48×48dp | `[已实现]`：`IconButton` 默认 48dp；树条目 `heightIn(min = 48.dp)`；展开箭头 48dp 槽位；picker 根目录行 48dp |
| 触达不重叠 | 相邻可点区域间隔 ≥ 8dp | `[已实现]`（网格 12dp、行内间隔 12dp） |
| 长按替代路径 | 长按菜单必须对 TalkBack 暴露非长按入口 | `[缺口 P1/T5]` 建议卡片 `customActions`（重命名/移动/删除），或在菜单外提供溢出按钮 |
| 手势非唯一 | 不要求滑动/长按才能完成核心任务 | `[已实现]` 核心任务均可点击完成 |

### 2.2 语义与朗读

| 项 | 要求 | 现状 |
|---|---|---|
| 图标语义 | 每个 `IconButton` 有 `contentDescription` | `[已实现]` 全量核对：返回/返回上级/目录/跳页/切换阅读模式/新建文件夹/导入文档/导入目录/搜索/排序/设置/退出搜索/清空关键词/展开/收起 |
| 装饰元素静默 | 纯装饰图标、缩略图、占位图标 `contentDescription = null` | `[已实现]` |
| 卡片整卡语义 | 朗读「文档名，12 页，需要密码」，而非逐个子节点 | `[缺口 P1/T5]` 建议 `Modifier.semantics(mergeDescendants = true)` + 组合描述 |
| 页码语义 | 阅读器顶栏朗读「第 5 页，共 12 页」而非「5 / 12」 | `[缺口 P1]` 建议 `contentDescription` 覆盖 |
| 加载语义 | 进度环有声明的「正在加载」状态 | `[缺口 P1]` 建议 `progressBarRangeInfo` / `stateDescription` |
| 错误可感知 | Snackbar 出现时被朗读；关键错误可达 | `[已实现]` 默认礼貌播报 |
| 大纲层级 | 朗读包含层级感（缩进视觉不可朗读） | `[缺口 P2]` 建议条目描述加「第 N 级」或使用标题语义 |

### 2.3 颜色与对比度

| 项 | 要求 | 现状 |
|---|---|---|
| 信息不依赖颜色 | 加密/损坏用图标 + 文本语义 | `[已实现]`（Lock/Warning + CD） |
| 正文对比度 ≥ 4.5:1 | 标题、正文、按钮 | `[已实现]`（默认色板） |
| 次要文本 ≥ 3:1 | 页码、元信息、空态说明 | `[缺口 P2/D8]` 空态与部分次要文本用 `outline`，建议统一 `onSurfaceVariant` |
| 选中态可辨 | 除背景色外有结构提示 | `[已实现]`（picker 选中背景 + 树展开箭头方向） |
| 不透明角标 | 深色角标上文字为白色，对比度足够 | `[已实现]`（黑 55% + 白字） |

### 2.4 焦点与顺序

| 项 | 要求 | 现状 |
|---|---|---|
| 弹窗初始焦点 | 打开含输入的弹窗，焦点落在输入框 | `[建议 P1/T5]` 用 `FocusRequester` |
| 弹窗关闭后焦点 | 回到触发元素 | `[建议 P1/T5]` |
| 阅读顺序 | 顶栏 → 内容区 → 浮层，与视觉顺序一致 | `[已实现]`（Compose 默认） |
| 键盘导航 | 外接键盘 Tab 可遍历顶栏与卡片 | 未验证，`[建议 P2]` 纳入验收 |

## 3. TalkBack 验收脚本（可直接执行）

1. 打开应用 → 朗读「书架」；根空态朗读「书架还是空的，点右上角 + 导入文档」；
2. 遍历顶栏 4~6 个动作，每个都有可理解的名称（无「按钮」「未标记」）；
3. 聚焦文档卡 → 一次朗读出名称 + 页数 + 是否加密（T5 完成后）；
4. 打开卡片菜单 → 可通过「操作」菜单触发重命名/移动/删除（T5 完成后）；
5. 进入阅读器 → 朗读「文档名，第 N 页，共 M 页」；
6. 打开大纲 → 加载态被朗读；空态朗读「本文档没有目录」；
7. 打开跳页 → 焦点在输入框，错误输入朗读范围提示；
8. 打开密码框 → 密码输入被掩码，错误提示被朗读；
9. 删除文件夹 → 对话框正文完整朗读（含「文档将移至根目录」）；
10. 备份恢复 → 确认对话框可完整朗读，取消后无操作发生。

## 4. 字体缩放验收脚本

| 步骤 | 预期 |
|---|---|
| 系统字号调至最大（约 200%） | 书架卡片标题 2 行后省略，不撑破卡片 |
| 进入阅读器 | 顶栏文档名 1 行省略，页码可见；动作图标不被挤出屏幕 |
| 打开设置/关于 | 全页可滚动，无文字被裁切 |
| 打开导入汇总（含 10+ 行） | 对话框可滚动，主按钮始终可见 |
| 打开任意输入弹窗 + 软键盘 | 输入框与按钮同时可见 |

## 5. 已知限制（需在验收中注明，避免误判缺陷）

1. 垂直模式跨宽度恢复的像素偏移有近似误差（同宽度精确）——旋转后位置可能有轻微偏移，属已知限制；
2. epub 水平模式按内容锚点重排，旋转后页码数字可能变化但阅读位置等义；
3. 水平模式只记录页码，`scrollOffsetY` 归 0，恢复后对齐页首；
4. 深色模式下缩略图为原图（不做暗化处理），避免与"内容变暗"混淆。
