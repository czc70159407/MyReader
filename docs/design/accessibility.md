# 响应式与无障碍规格

> 本文件是响应式与无障碍的**唯一**验收清单。实现现状见 [`../ui-design.md`](../ui-design.md)；每条结论必须能在真机或 Compose 测试中复现。

## 1. 响应式矩阵

| 场景 | 要求 | 现状 | 验证方式 |
|---|---|---|---|
| 手机竖屏 360dp | 书架 ≥3 列；顶栏动作不溢出、不换行、不压缩标题到不可读 | `[已实现]` 网格；`[缺口]` 6 图标需实测 | 360dp 模拟器截图 |
| 手机横屏 640dp+ | 书架列数随宽度增加；阅读器渲染区铺满，无留白 | `[已实现]`（`Adaptive(108dp)`） | 旋转后截图 |
| 平板 / 折叠屏展开 | 同上；设置页内容建议限宽 600dp 居中 | `[建议 P2]` 限宽未做 | 840dp 模拟器 |
| 分屏（600dp 以下多窗口） | 尺寸变化后渲染重建，不白屏、不丢进度 | `[已实现]`（去抖 150ms + 锁存页） | 分屏拖动后截图 + 页码比对 |
| epub 旋转/分屏 | 按内容锚点重排，顶栏分母实时更新 | `[已实现]`（`onPageCountChanged`） | 竖→横→竖 三次分母 |
| 软键盘弹出 | 对话框内输入时，主/次按钮与输入框均可见 | `[已知坑]` 真机曾出现按钮被顶移 | 弹窗截图 + 重新定位点击 |
| 字体缩放 200% | 顶栏双行标题、卡片 2 行标题、汇总对话框不裁切关键信息 | 未系统验证 | 系统字号最大后逐页走查 |
| RTL | 缩进用 `start/end`，箭头用 `AutoMirrored` | `[已实现]` | 开发者选项强制 RTL |
| 深色模式 | 三选一实时生效；首帧不闪白 | `[已实现]` | 设置切换 + 冷启动 |
| 大屏阅读器 | 垂直模式长文档滚动流畅，无 OOM | `[已实现]`（字节预算 LruCache） | 200+ 页 PDF 连续滚动 |

## 2. 无障碍清单（逐项打勾）

### 2.1 触达与操作

| 项 | 要求 | 现状 |
|---|---|---|
| 最小触达 | 所有可点元素 ≥ 48×48dp | `[已实现]`：`IconButton` 默认 48dp；树条目 `heightIn(min = 48.dp)`；展开箭头 48dp 槽位；picker 根目录行 48dp |
| 触达不重叠 | 相邻可点区域间隔 ≥ 8dp | `[已实现]`（网格 12dp、行内间隔 12dp） |
| 长按替代路径 | 长按菜单必须对 TalkBack 暴露非长按入口 | `[已实现 T5]` 卡片 `customActions`（文件夹 4 项 / 文档 3 项，见 `LibraryCards.kt`） |
| 手势非唯一 | 不要求滑动/长按才能完成核心任务 | `[已实现]` 核心任务均可点击完成 |

### 2.2 语义与朗读

| 项 | 要求 | 现状 |
|---|---|---|
| 图标语义 | 每个 `IconButton` 有 `contentDescription` | `[已实现]` 全量核对：返回/返回上级/目录/跳页/切换阅读模式/新建文件夹/导入文档/导入目录/搜索/排序/设置/退出搜索/清空关键词/展开/收起 |
| 装饰元素静默 | 纯装饰图标、缩略图、占位图标 `contentDescription = null` | `[已实现]` |
| 卡片整卡语义 | 朗读「文档名，12 页，需要密码」，而非逐个子节点 | `[已实现 T5]` 点击容器单节点语义（`clearAndSetSemantics` 组合描述 + `role` + `onClick`/`onLongClick`/`customActions`），模板见 `copy.md` §9.1；状态角标 CD 置 null 避免重复播报。**注意**：`mergeDescendants` 挂在 `Card` 上会被平台拆成两个 `AccessibilityNodeInfo`（真机实测重复播报），门禁见 `app` 模块 `LibraryA11yTreeTest` |
| 页码语义 | 阅读器顶栏朗读「第 5 页，共 12 页」而非「5 / 12」 | `[缺口 P1]` 建议 `contentDescription` 覆盖 |
| 加载语义 | 无可见文案的加载环需可被读屏感知 | `[已实现 T5]` 书架首帧 / 阅读器 Loading 环加 CD「正在加载」（`loading_generic`）；备份/大纲等已有文本的加载态不重复加 |
| 错误可感知 | Snackbar 出现时被朗读；关键错误可达 | `[已实现]` 默认礼貌播报 |
| 大纲层级 | 朗读包含层级感（缩进视觉不可朗读） | `[缺口 P2]` 建议条目描述加「第 N 级」或使用标题语义 |

### 2.3 颜色与对比度

| 项 | 要求 | 现状 |
|---|---|---|
| 信息不依赖颜色 | 加密/损坏用图标 + 文本语义 | `[已实现]`（Lock/Warning + CD） |
| 正文对比度 ≥ 4.5:1 | 标题、正文、按钮 | `[已实现]`（默认色板） |
| 次要文本 ≥ 3:1 | 页码、元信息、空态说明 | `[已实现 T6]` 空态与次要文本统一 `onSurfaceVariant`（全仓无 `outline` 文本） |
| 选中态可辨 | 除背景色外有结构提示 | `[已实现]`（picker 选中背景 + 树展开箭头方向） |
| 不透明角标 | 深色角标上文字为白色，对比度足够 | `[已实现]`（黑 55% + 白字） |

### 2.4 焦点与顺序

| 项 | 要求 | 现状 |
|---|---|---|
| 弹窗初始焦点 | 打开含输入的弹窗，焦点落在输入框 | `[已实现 T5]` 4 个输入弹窗 + 搜索态自动聚焦（`withFrameNanos` 后请求，避独立窗口焦点时序；容器 `imePadding` 防键盘顶移按钮） |
| 弹窗关闭后焦点 | 回到触发元素 | `[建议 P1/T5]` |
| 阅读顺序 | 顶栏 → 内容区 → 浮层，与视觉顺序一致 | `[已实现]`（Compose 默认） |
| 键盘导航 | 外接键盘 Tab 可遍历顶栏与卡片 | 未验证，`[建议 P2]` 纳入验收 |

## 3. TalkBack 验收脚本

> 只有**必须靠朗读判定或手势触发**的项才需要人工；文本语义、输入框焦点与键盘状态可用 `uiautomator dump` + `dumpsys input_method` 自动取证，不重复人工（取证方式见 `docs/acceptance-files.md`）。

### 3.1 全量脚本（10 步）

1. 打开应用 → 朗读「书架」；根空态朗读「书架还是空的，点右上角 + 导入文档」；
2. 遍历顶栏 4~6 个动作，每个都有可理解的名称（无「按钮」「未标记」）；
3. 聚焦文档卡 → 一次朗读出名称 + 页数 + 是否加密（判定细则见 §3.2 A 组）；
4. 打开卡片菜单 → 可通过「操作」菜单触发重命名/移动/删除（判定细则见 §3.2 B 组）；
5. 进入阅读器 → 朗读「文档名，第 N 页，共 M 页」；
6. 打开大纲 → 加载态被朗读；空态朗读「本文档没有目录」；
7. 打开跳页 → 焦点在输入框，错误输入朗读范围提示；
8. 打开密码框 → 密码输入被掩码，错误提示被朗读；
9. 删除文件夹 → 对话框正文完整朗读（含「文档将移至根目录」）；
10. 备份恢复 → 确认对话框可完整朗读，取消后无操作发生。

### 3.2 T5 语义专项（操作级，约 8 分钟）

> **暂停（用户决策 2026-10-29）**：TalkBack 人工走查与「操作」菜单触发项暂不执行、不列入待办；本节保留为日后抽查脚本，日常回归以 `LibraryA11yTreeTest` 插桩门禁为准。

**前置**：设置 → 其他设置 → 无障碍 → 视觉 → TalkBack（一加 ColorOS 路径）；首次开启的「无障碍套件」通知权限选允许；确认书架已有 ≥3 张文档卡。

**手势**：单指右滑 / 左滑 = 上 / 下一焦点；双击 = 激活当前焦点；**上滑后立刻右滑**（两段连续）= 本地上下文菜单；双指上下滑 = 滚动。

**自动化门禁**：A / B 两组的判据已由设备插桩测试 `app/src/androidTest/java/com/myreader/LibraryA11yTreeTest.kt` 覆盖——直接读平台 `AccessibilityNodeInfo`，断言每张卡是**单一** `clickable && contentDescription` 节点、其下无文本子节点、`actionList` 含 `重命名/移动/删除`。回归命令：

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest "-Pandroid.testInstrumentationRunnerArguments.class=com.myreader.LibraryA11yTreeTest"
```

本节人工步骤只在「改动卡片结构 / 升级 Compose 或 TalkBack」后抽查朗读，不再作为每次验收的必经项。

> **运行注意**：测试自身向 DB 播种 `a11y_test.pdf` 夹具（结束后删除），不依赖设备既有书架；但 `connectedDebugAndroidTest` 跑完会**卸载被测应用（数据清空）**，真机验收前后需自行备份 / 恢复（或使用独立测试机）。

#### A 组：卡片整卡朗读

| 步骤 | 操作 | 通过标准 |
|---|---|---|
| A1 | 右滑至 `outline_test.pdf` 卡 | 焦点框**包住整张卡**，一次读「outline_test.pdf，40 页」 |
| A2 | 右滑至 `encrypted_test.pdf` 卡 | 一次读「encrypted_test.pdf，3 页，需要密码」，锁角标不单独播报 |
| A3 | 右滑至 `epub_test.epub` 卡 | 一次读「epub_test.epub，EPUB」，格式角标不单独播报 |
| A4 | 右滑至任一文件夹卡 | 一次读「<名称>，文件夹」 |

> 判定要点：**一张卡 = 一个焦点位**。同一张卡需右滑 2~3 次才读完（如先读标题、再读页数）即判失败。

#### B 组：长按替代路径（customActions）

| 步骤 | 操作 | 通过标准 |
|---|---|---|
| B1 | 焦点在文档卡 → 上滑后右滑 | 本地上下文菜单列出「重命名 / 移动 / 删除」3 项 |
| B2 | 右滑选中「重命名」并双击 | 弹窗打开且输入框已聚焦、键盘弹出 |
| B3 | 焦点在文件夹卡 → 上滑后右滑 | 菜单列出「重命名 / 移动 / 删除 / 新建子目录」4 项 |

#### C 组：加载语义

| 步骤 | 操作 | 通过标准 |
|---|---|---|
| C1 | 从最近任务划掉 MyReader 后重开，立刻右滑 | 听到「正在加载」 |
| C2 | 打开 40 页 PDF 的瞬间右滑 | 听到「正在加载」 |

> 本地库与 40 页 PDF 加载均在 300ms 内，**听不到记 `N/A`，不算失败**（代码与 `LibraryComponentsTest` 已覆盖语义配置）。

## 4. 字体缩放验收脚本

| 步骤 | 预期 |
|---|---|
| 系统字号调至最大（约 200%） | 书架卡片标题 2 行后省略，不撑破卡片 |
| 进入阅读器 | 顶栏文档名 1 行省略，页码可见；动作图标不被挤出屏幕 |
| 打开设置/关于 | 全页可滚动，无文字被裁切 |
| 打开导入汇总（含 10+ 行） | 对话框可滚动，主按钮始终可见 |
| 打开任意输入弹窗 + 软键盘 | 输入框与按钮同时可见 |

## 5. 已知限制（需在验收中注明，避免误判缺陷）

1. 垂直模式跨宽度恢复的像素偏移有近似误差（同宽度精确）——旋转后位置可能有轻微偏移，属已知限制；
2. epub 水平模式按内容锚点重排，旋转后页码数字可能变化但阅读位置等义；
3. 水平模式只记录页码，`scrollOffsetY` 归 0，恢复后对齐页首；
4. 深色模式下缩略图为原图（不做暗化处理），避免与"内容变暗"混淆。
