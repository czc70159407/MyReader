# 流程 · 书签（M10 设计预留）

- 状态：**已实现（M10-C，2026-10-30）**——入口/面板/跳转/删除/加载失败重试；实现差异见 §8
- 优先级：M10（v1.3）
- 代码落点（计划）：`feature/reader/BookmarkSheet.kt`、`ReaderScreen.kt`、`ReaderViewModel.kt`；`core:data` 新增 `BookmarkEntity/Dao` 与 `MIGRATION_1_2`
- 执行计划：以 `docs/m10-plan.md` 为准；本文件只定义交互与状态，冲突时服从执行计划

## 1. 范围

**章节级书签**：记录「当前阅读位置」的稳定锚点（页码式记 `page`；流式 epub 记 bookmark/CFI 串），支持新建、跳转、删除。

明确不在本次范围：文本高亮、批注、跨文档书签聚合（M11 候选）。

## 2. 入口与布局

```
阅读器顶栏：  [←] 标题        [书签][目录][跳页][模式]
                                   ↓
┌────────────────────────────────────┐
│ 书签                         (面板) │
│ + 添加当前位置书签                    │
│ ─────────────────────────────────  │
│ 第 3 页    2026-10-26 14:05        │
│ 第 12 页   2026-10-20 09:31        │
│                                    │
│ （空态）暂无书签                     │
└────────────────────────────────────┘
```

- 面板复用 `OutlineSheet` 的 `ModalBottomSheet` 模式，避免新增页面路由。
- 排序：按页码升序（流式按解析页码）；同日多次以时间倒序。
- 条目文案：`第 {page+1} 页`（页码式）/ `第 {page+1} 页附近`（流式近似）；右侧时间 `yyyy-MM-dd HH:mm`。

## 3. 交互

| 操作 | 行为 | 反馈 |
|---|---|---|
| 顶栏「书签」 | 打开面板，懒加载当前文档书签 | 加载态 |
| 「添加当前位置书签」 | 以当前进度创建；重复位置（同页/同锚点）去重 | Snackbar「已添加书签」/「该位置已有书签」 |
| 点击条目 | 跳转到该书签位置并关闭面板 | 顶栏页码更新 |
| 条目长按 | 弹出「删除书签」 | 删除确认（可选） |
| 空态 | 文案 + 引导按钮 | `empty_bookmarks` |

规则：

1. 添加时若当前位置已存在书签：不新增，聚焦到已有条目并提示「该位置已有书签」。
2. 跳转与大纲跳页共用 clamp 逻辑（越界不落库）。
3. 删除为即时操作（单项、可再次添加），不做二次确认；提供 Snackbar 便于感知。
4. 删除当前正在阅读位置的书签不影响进度。

## 4. 状态矩阵

| 状态 | 触发 | 展示 | 动作 |
|---|---|---|---|
| 加载 | 打开面板 | 环 + 「正在加载书签…」 | — |
| 空 | 无书签 | `empty_bookmarks` + 添加按钮 | 添加 |
| 有数据 | n ≥ 1 | 列表 + 顶部添加行 | 跳转/删除/添加 |
| 错误 | 数据层异常 | 「书签加载失败」+ 重试 | 重试 |
| 重复添加 | 当前位置已存在 | 列表定位到该条目 | — |
| 文档未就绪 | 面板不可打开（仅在 Ready 态提供入口） | — | — |

## 5. 数据与迁移（设计约束）

1. 新增表，不改既有表列：`bookmarks(id, documentId, page, anchor, createdAt)`；`documentId` 外键级联删除（删文档即删书签）。
2. schema v1 → v2 必须手写 `MIGRATION_1_2` + `MigrationTest` 门禁；禁止 `fallbackToDestructiveMigration`。
3. 备份兼容：`BackupCodec.schemaVersion = 2`；导入 v1 旧备份时书签为空且不报错。
4. 删除文档/目录时书签随文档级联清理（目录删除导致文档回根时书签保留）。

## 6. 无障碍

| 项 | 要求 |
|---|---|
| 条目朗读 | 「第 3 页，2026-10-26 14:05，双击跳转」 |
| 删除替代 | 长按之外提供读屏自定义操作「删除」 |
| 添加按钮 | 明确动词与结果，48dp |
| 空态 | 可朗读，引导可操作 |

## 7. 验收场景

1. 打开 PDF 第 5 页 → 添加书签 → 面板显示「第 5 页」；
2. 返回书架 → 重进 → 面板书签仍在（持久化）；
3. 点击书签 → 跳到第 5 页，面板关闭；
4. 同一页重复添加 → 不新增，提示已有；
5. 删除书签 → 列表移除，Snackbar 提示，重启后仍不存在；
6. epub：添加书签 → 旋转/重排 → 点击书签仍定位到同一内容位置（锚点稳定）；
7. 升级安装（v1 → v2）：原有文档/进度/目录保留，书签为空；
8. 从 v1 备份恢复：成功且书签为空，不报错；
9. 删除含书签的文档：书签随之删除，无残留（DB 校验）。

## 8. 实现差异（M10-C 落地记录）

1. **删除入口**：由「长按弹出删除」改为列表行尾部显式删除图标（CD「删除书签」）——更易发现且读屏可直接到达；即时删除 + Snackbar，无二次确认。
2. **顶栏图标态**：`Bookmark`（实心）/ `BookmarkBorder`（描边）区分当前页/锚点是否已收藏，判据与列表一致（页码式比 page、流式比 page + loc）。
3. **文案**：页码式 label「第 N 页」；流式 label「第 N 屏」（page 取 `EpubProgressCodec` 解析值）。
4. **跳转**：页码式写 `ProgressPayload.Page(page, scrollOffsetY)` 并立即落库；流式以 `loc` 重建 `ProgressPayload.Cfi`，由渲染端解析锚点定位（跨重排稳定），随后回发 CFI 落库。
5. **加载失败**：观察流异常 → 面板「书签加载失败 + 重试」（重建观察）。
6. **无障碍**：行点击跳转、删除为可聚焦图标按钮；顶部添加按钮 48dp；空态/失败态文案可读。
7. **失败兜底（M10-C review）**：写库异常转 Snackbar（`err_bookmark_add`/`err_bookmark_delete`），不让协程异常冒泡崩溃；流式 payload 无有效 `loc` 时提示 `err_bookmark_unavailable` 且**不写库**——避免降级成 `anchor=null` 的页码式书签污染列表（备份恢复侧仅接受十进制锚点）。
