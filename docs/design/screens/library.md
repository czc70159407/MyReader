# 页面 · 书架与搜索

- 状态：评审通过
- 优先级：P0（顶栏收纳 T2）/ P1（无障碍 T5）
- 关联决策：D2、D5、D8
- 路由：`library?folderId={id}`（缺省/`-1L` = 根）
- 代码落点：`feature/library/LibraryScreen.kt`（编排）、`LibraryCards.kt`、`LibraryThumbnails.kt`、`SortMenu.kt`、`LibraryViewModel.kt`

## 1. 目标与入口

| 用户目标 | 入口 | 成功判定 |
|---|---|---|
| 浏览/进入目录 | 启动应用（根）、点击文件夹卡 | 面包屑与网格同步 |
| 打开文档 | 点击文档卡/最近卡 | 进入阅读器并恢复进度 |
| 导入文档 | 顶栏 `+` | 汇总提示出现、网格刷新 |
| 批量导入目录 | 顶栏 `⋮` → 导入目录 | 进度 → 汇总对话框 |
| 整理 | 长按卡片 / `⋮`（T2） | 菜单或弹窗出现 |
| 检索 | 顶栏搜索 | 结果或空态 |
| 改偏好 | 顶栏设置 | 设置页 |

## 2. 布局

```
┌──────────────────────────────────────────────┐
│ [←] 书架 / A / B      [+ 导入][搜索][⋮][设置]   │  TopAppBar（D2）
├──────────────────────────────────────────────┤
│ 最近阅读（仅根 + 有记录）                        │
│ ┌────┐┌────┐┌────┐  ← LazyRow 100dp 卡         │
│                                                                  │
│ ┌────┐┌────┐┌────┐  ← LazyVerticalGrid           │
│ │📁  ││📄  ││📄  │    Adaptive(108dp), gap 12dp   │
│ └────┘└────┘└────┘                              │
│                                                                  │
│           ● 正在导入 3/42…   [取消]              │  底部胶囊（D3）
└──────────────────────────────────────────────┘
```

- 内容分支固定为四种：`initialLoad` → 搜索态 → 空态 → 网格。顺序不可调整（防空态闪现）。
- 文件夹在前、文档在后；同一 `LazyVerticalGrid`，key 前缀 `f_` / `d_` / `r_`，不冲突。

## 3. 状态矩阵

| 状态 | 触发 | 展示 | 可执行动作 |
|---|---|---|---|
| 首帧加载 | 三个数据流未首次发射 | 整屏进度环 | 无 |
| 根空 | 根目录无文件夹/文档 | 图标 + `empty_library_root` | 顶栏 `+`、新建文件夹 |
| 子目录空 | 同上 + 非根 | 图标 + `empty_folder` | 顶栏 `+` |
| 有内容 | 有文件夹或文档 | 最近条（根）+ 网格 | 全部 |
| 搜索态·输入中 | `searchOpen && query` 空或防抖中 | 维持浏览内容 | 输入 |
| 搜索态·无结果 | `searchResults` 空列表 | 图标 + `empty_search` | 清空/退出 |
| 搜索态·有结果 | 结果非空 | 全库结果网格 | 点击/长按 |
| 导入中 | `importing` | 底部胶囊 + 禁用导入入口 | 其他操作可用；`[建议 D3]` 取消 |
| 目录导入完成 | `importSummary != null` | 汇总对话框 | 知道了 |
| 目录结构读取失败 | 移动文件夹前置失败 | 「无法移动」对话框 | 知道了 |
| 子目录数据被删 | 当前 folderId 不存在 | 回落空态，面包屑退「书架」 | 返回上级/导入 |

## 4. 交互细则

### 4.1 浏览与导航

1. 点击文件夹卡 → `navigate(library?folderId=id)`；返回键/返回上级 → `popBackStack()`。
2. 面包屑为单行，超长省略；当前级加粗；不提供逐级点击跳转（现状限制，`[建议 P2]` 可改为可点分段）。
3. 目标子目录被删除时，列表转空、标题回落「书架」，不崩溃（`[已实现]`）。

### 4.2 卡片操作

- 长按文件夹：重命名 / 移动 / 删除 / 新建子目录。
- 长按文档：重命名 / 移动 / 删除。
- 菜单点击后先关闭菜单再执行动作；删除走确认弹窗；成功后 Snackbar。

### 4.3 导入

- 顶栏 `+`：`OpenMultipleDocuments` + mime 白名单（pdf / epub+zip / x-cbz / comicbook+zip / oxps / ms-xpsdocument / text/plain）。
- 选完文件 → 目录选择弹窗（默认当前目录）→ 导入。
- `[建议 D5]` 多选 ≥2 且存在失败/跳过时，结果改为汇总对话框（与目录导入同款）。
- 单文件成功仍走 Snackbar，保持轻量。

### 4.4 搜索

- 进入：顶栏搜索图标 → `searchActive`，标题槽变输入框，动作区隐藏。
- 输入：300ms 防抖；`searchResults == null` 表示"非搜索态"，空列表表示"无命中"。
- 退出：返回键（`BackHandler`）或返回图标 → 清空关键词并恢复浏览；**不得 pop 导航栈**。
- 清空图标仅在有关键词时出现。
- `[建议 P1]` 结果区顶部显示「共 N 项」提示全库范围。

### 4.5 排序

- `⋮` 菜单排序段（D2）：标题 / 最近阅读 / 添加时间 / 大小；当前项勾选。
- 选中即写 `LibraryPrefs`，网格即时重排，重启保持；与设置页「书架排序」同源双向同步。
- 搜索态不展示排序（结果固定按标题）。

### 4.6 并发与重复点击

- 导入期间再次点击导入入口无效（`enabled = false`）。
- 快速连点卡片：导航由 `NavController` 去重（同目的地同参数），不额外加节流。
- 快速连续移动/删除：操作串行（`launchOp` 顺序执行），无并发写库。

## 6. 表单校验

本页无直接输入表单（搜索除外）：

| 字段 | 规则 | 时机 | 反馈 |
|---|---|---|---|
| 搜索关键词 | 空 → 退出结果态；`[建议]` ≤ 100 字符 | 输入期 | 无错误提示（静默截断） |

其余校验见 `components/dialogs.md`。

## 7. 无障碍

| 项 | 要求 |
|---|---|
| 卡片整卡朗读 | `[建议 T5]` merge 语义：名称 + 页数/格式 + 是否需要密码 |
| 长按替代 | `[建议 T5]` `customActions` 提供重命名/移动/删除 |
| 顶栏 | 4 个动作均有 CD；`⋮` 文案 `act_more` |
| 空态 | 图标静默、文案可读、入口指引可朗读 |
| 导入胶囊 | `liveRegion`，进度变化可播报（节流） |
| 触达 | 卡片、按钮 ≥ 48dp |

## 8. 响应式

| 场景 | 变化 |
|---|---|
| 360dp | 3 列；顶栏 4 动作（D2 后） |
| 600dp+ | 列数自适应增加；最近条每屏更多卡 |
| 横屏 | 列数增加；顶栏保持单行 |
| 字体 200% | 卡片标题 2 行省略；面包屑省略；动作不换行 |
| 分屏 | 列数减少，滚动位置保留（LazyGrid 状态） |

## 9. 验收场景

1. 空库启动：进度环 → 根空态 → 点击 `+` 可进系统选择器；
2. 新建 `A/B` 两级目录：面包屑「书架 / A / B」，返回两级回根；
3. 导入 1 损坏 + 1 加密 + 1 正常：各状态角标正确，提示文案与 `copy.md` 一致；
4. 搜索「outline」：命中跨目录结果（含根目录文档），300ms 内出结果；清空恢复浏览；返回键先退出搜索；
5. 排序切「大小」再切「最近阅读」：立即重排，进设置页看到同一选中项，重启保持；
6. 移动文件夹选自身/后代：红字 + 确定禁用；读取结构失败时只弹「无法移动」；
7. 删除非空目录：文档回根，Snackbar 文案含「已移至根目录」；
8. 360dp 顶栏无溢出（D2 后），`⋮` 内两项动作可用；
9. 导入中 `+` 与「导入目录」置灰，其余操作可用。
