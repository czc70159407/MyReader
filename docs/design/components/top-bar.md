## 1. 书架顶栏

### 1.1 现状（`[已实现]`）

```
┌──────────────────────────────────────────────────────────────┐
│ [←] 书架 / A / B(粗)   [新建][导入][导入目录][搜索][⋮排序][设置] │
└──────────────────────────────────────────────────────────────┘
```

- 标题槽：非搜索态为面包屑单 `Text`（根「书架」弱化 + 当前级加粗，`maxLines = 1`，`Ellipsis`）；搜索态替换为透明 `TextField`。
- `navigationIcon`：搜索态 = 退出搜索；非根目录 = 返回上级；根目录 = 无。
- `actions`（非搜索态）：新建文件夹 → 导入文档 → 导入目录 → 搜索 → 排序（`⋮`）→ 设置。
- 导入进行中：两个导入按钮 `enabled = false`。
- 搜索态：`actions` 全部隐藏。

### 1.2 修订（D2 / T2）

```
┌────────────────────────────────────────────┐
│ [←] 书架 / A / B(粗)      [+ 导入][搜索][⋮][设置] │
└────────────────────────────────────────────┘
                    ⋮ 菜单：
                    ┌──────────────────┐
                    │ 新建文件夹          │
                    │ 导入目录            │
                    ├──────────────────┤
                    │ ✓ 标题             │
                    │   最近阅读          │
                    │   添加时间          │
                    │   大小             │
                    └──────────────────┘
```

规则：

1. 顶栏固定 4 个动作位：导入文档（`+`）、搜索、`⋮`（更多）、设置。
2. `⋮` 菜单分两段，用 `HorizontalDivider` 分隔：动作段（新建文件夹、导入目录）+ 排序段（4 项，当前项 trailing `Check`，`contentDescription = act_current_sort`）。
3. 排序项文案与设置页「书架排序」完全一致（同源 `sortLabel`）。
4. 菜单项点击后立即关闭菜单再执行动作（避免菜单残影随导航离场）。
5. 导入进行中：`+` 与菜单内「导入目录」均置灰；`⋮` 本身可用（新建文件夹不受影响）。
6. 搜索态：隐藏 `+`、`⋮`、设置，仅保留退出搜索与输入框。

> 替代方案（未采纳）：把「新建文件夹」改为 FAB。理由：FAB 会遮挡网格右下内容，且与「导入」主入口争夺视觉权重。评审如需改回，需同时调整 `tokens.md` 层级。

### 1.3 状态矩阵

| 状态 | 触发 | 展示 | 动作 |
|---|---|---|---|
| 根目录 | `folderId == null` | 无返回图标，标题仅「书架」 | 全部可用 |
| 子目录 | 有 `folderId` | 返回上级图标 | 全部可用 |
| 搜索态 | `searchOpen` | 输入框 + 退出搜索 | 输入/清空/退出 |
| 导入中 | `importing` | 导入入口禁用 | 其他可用 |
| 超长路径 | 面包屑 > 1 行宽度 | 单行省略，保留当前级粗体（可能被截断，属已知限制） | — |
| 大字体 200% | 系统字号最大 | 标题单行省略；动作仍为 4 个 | — |

## 2. 阅读器顶栏

### 2.1 现状（`[已实现]`）

```
┌────────────────────────────────────────────┐
│ [←] 文档标题（1 行省略）        [目录][跳页][模式] │
│     5 / 12                                 │
└────────────────────────────────────────────┘
```

- 标题槽为 `Column`：文档名（默认标题样式，`maxLines = 1`，`Ellipsis`）+ 页码 `labelSmall`。
- 页码：`(uiPage + 1).coerceAtMost(pageCount) / pageCount`；分母取实时页数（epub 重排后随动）。
- 动作：目录 → 跳页 → 切换阅读模式（会话态，不回写设置）。
- 返回：先 flush 进度再 `popBackStack`。

### 2.2 修订

1. **M10 书签**：动作区扩展为 `[书签][目录][跳页][模式]`；窄屏溢出评估与书架同批（届时若不满足 360dp，则书签入口移入「目录」面板顶部 Tab）。
2. **沉浸模式（D4，待预研）**：轻点内容区切换顶栏显隐；默认显示，滚动时自动隐藏，轻点恢复。实现前置条件：
   - 水平模式：确认 `ReaderView` 是否消费 `ACTION_UP`（点击翻页）；
   - 垂直模式：`LazyColumn` 上 `detectTapGestures` 与滚动的手势竞争；
   - 结论写入本节后再排期，预研未通过则保持常驻顶栏。

### 2.3 状态矩阵

| 状态 | 触发 | 展示 | 动作 |
|---|---|---|---|
| 加载 | 打开中 | 顶栏不渲染（仅整屏进度环） | — |
| 就绪 | 打开成功 | 标题 + 页码 + 3~4 动作 | 全部可用 |
| 需密码 | 加密文档 | 顶栏不渲染（仅弹窗） | 打开/取消 |
| 失败 | 打开失败 | 顶栏不渲染（仅失败页） | 返回书架 |
| 页数未知 | `pageCount <= 0` | 页码显示 `1 / 0` 属缺陷，`[建议]` 改为仅显示页码不显示分母 | — |

> `[缺口]` 打开前或页数为 0 时 `1 / 0` 的展示需在实现中兜底（`pageCount` 取 `max(0)` 判断）。

## 3. 无障碍

| 项 | 要求 |
|---|---|
| 触达 | 全部为 `IconButton`（48dp） |
| 语义 | 每个图标必须有 `contentDescription`；`⋮` 为 `act_more`（新增键，文案「更多」） |
| 页码朗读 | `[建议 T5]` 标题槽组合语义：`{title}，第 {page} 页，共 {count} 页` |
| 焦点 | 返回键（若有）为首个焦点，其次标题，再次动作区 |

## 4. 验收场景

1. 360dp 设备打开根书架：4 个动作 + 标题不重叠、不省略到不可读；
2. 子目录：出现返回上级，点击回上级且面包屑同步；
3. 打开 `⋮`：动作段 2 项 + 分隔线 + 排序 4 项，当前排序有勾选；
4. 选择「大小」排序：菜单关闭、网格立即重排、重启后保持（与设置页同源）；
5. 导入进行中：`+` 与「导入目录」置灰，`⋮` 与设置可点；
6. 搜索态：动作区隐藏，返回键退出搜索而非返回上级；
7. 阅读器 epub：旋转/分屏后分母随实际排版页数变化；
8. 阅读器页数为 0 时不出现 `1 / 0` 的错误展示（T2 同批修）。
