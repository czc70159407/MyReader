## 2. 统一原则

1. **加载不混空态**：首帧必须有加载态，禁止先渲染空态再跳数据（书架 `initialLoad` 已按此实现）。
2. **空态给出路**：至少一条文字指引或一个高亮入口；"什么都没有"式空态不合格。
3. **错误必须可结束**：错误态必须提供「返回/重试/关闭」之一；只有文案没有出口视为缺陷。
4. **文案层级**：标题用 `bodyLarge`，说明用 `bodyMedium`，技术明细用 `labelSmall`。
5. **颜色（D8）**：空态与次要说明统一 `onSurfaceVariant`；`outline` 仅用于纯装饰（角标默认态、图标描边）。
6. **不得只用颜色区分**：错误态同时有文案；加密/损坏同时有图标。
7. **不制造闪烁**：异步加载完成前不显示与结果矛盾的占位（如空态图标）。

## 3. 视觉规格

| 元素 | 规格 |
|---|---|
| 空态容器 | `fillMaxSize` + padding 32dp，水平/垂直居中 |
| 空态图标 | 64dp，`onSurfaceVariant`（D8），`contentDescription = null` |
| 空态文案 | 与图标间距 16dp，`bodyLarge`，居中，可含换行 |
| 失败页 | padding 32dp，error 色 `bodyLarge`，按钮间距 24dp |
| 底部胶囊 | 距底 16dp，横向铺满减 16dp，圆角 24dp，`surfaceVariant` 底，内边距 16/10dp，环 18dp |
| 面板内加载 | 24dp padding，环 + 文案间距 12dp |
| 备份进度 | 环 + 文案（间距 12dp）+ 全宽线性进度（底部 4dp） |

## 5. 验收场景

1. 冷启动（库为空）：先看到进度环，再看到根空态，无空态闪现；
2. 进入空子目录：文案为「此文件夹为空」，且顶栏 `+` 可导入到当前目录；
3. 搜索无结果：显示「未找到匹配文档」，清空关键词后恢复浏览；
4. 导入 42 个文件：文案从「正在扫描目录…」切到「正在导入 3/42…」，无重复/跳号；
5. 打开加密 PDF：密码框；取消后回到书架，书架无残影；
6. 阅读器打开损坏文件：失败页有文案与「返回书架」，可点击返回；
7. 大纲快速关闭：不出现「目录加载失败」（取消传播，已有回归）；
8. 备份 100+ MB：进度环与线性进度同步推进，完成后 Snackbar；
9. 深色模式下所有空态/失败页文本对比度可读（D8 后）。
